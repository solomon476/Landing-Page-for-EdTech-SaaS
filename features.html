4. Exam & Report Card Management

End-to-end evaluation suite for Continuous Assessment Tests (CATs) and terminal exams, producing beautiful, compliant report cards in PDF format.

  • CBC & Standard Grading: Native support for Exceeding Expectations (EE), Meeting Expectations (ME), Approaching (AE), and Below (BE).
  • Automated Report Generation: Batch generate Term 1, 2, and 3 report cards with principal comments and charts.
  • PDF Export & Parent Access: Parents can view and download tamper-proof official PDF transcripts via the portal.
